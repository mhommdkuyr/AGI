# تصميم واجهة وكيل الويب

هذه الوحدة تحفظ مواصفات الواجهة التي تم تنفيذها للنسخة الهاتفية الأولية.

## الشاشات
- الرئيسية: إدخال الهدف والميزانية.
- التنفيذ المباشر: صورة المتصفح، الحالة، الجولات، والإلغاء.
- تدخل المستخدم: إشعار المصادقة أو التحقق مع استكمال المهمة.
- المهام: السجل والاستهلاك.
- الإعدادات: الحساب، الخصوصية، الإشعارات، الفوترة، والأمان.

## المظهر
- الاتجاه: من اليمين إلى اليسار.
- مقاس إطار الهاتف المرجعي: 390 × 844.
- واجهة داكنة.
- أزرق كإجراء أساسي.
- أخضر للنجاح، برتقالي للتدخل، أحمر للفشل.
- بطاقات دائرية بحواف كبيرة.
- شاشة المتصفح عنصر مركزي أثناء التنفيذ.

## الربط بالتطبيق
الواجهة الحالية تستخدم واجهات البرمجة التالية:
- إنشاء المهمة.
- قراءة حالة المهمة.
- قراءة لقطة المتصفح الحية.
- إرسال تحكم بشري محدود أثناء حالة الانتظار.
- استئناف المهمة بعد تدخل المستخدم.
- إلغاء المهمة.

## مصدر التصميم
النسخة القابلة للاستيراد إلى فيجما موجودة كملف SVG مرفق مع التسليم، إضافة إلى ملف رموز التصميم بصيغة JSON.
