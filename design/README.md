# تصميم واجهة وكيل الويب

هذه الوحدة تحفظ مواصفات واجهة التطبيق وتربطها بمحرك التنفيذ.

## ملف فيجما

الملف الفعلي في فيجما:
https://www.figma.com/design/JHAMCaPNflO20n7Gc3ZMal

اسم الملف: AGI — Web Agent Mobile

## الشاشات

- الرئيسية: إدخال الهدف والميزانية ونمط التنفيذ.
- التنفيذ المباشر: صورة المتصفح، الحالة، الجولات، الإجراء الحالي، الاستهلاك، والإلغاء.
- تدخل المستخدم: جلسة المتصفح الحية، سبب التوقف، أدوات النقر والكتابة والتمرير، ثم إعادة التحكم للوكيل.
- المهام: السجل وحالات النجاح والفشل والاستهلاك.
- الحساب والفوترة: الخطة والرصيد وحدود الاستخدام والفواتير.
- الإعدادات والأمان: الحساب والخصوصية والإشعارات والجلسات.

## المظهر

- الاتجاه: من اليمين إلى اليسار.
- المقاس المرجعي: 390 × 844.
- خلفية داكنة متعددة الطبقات.
- أزرق للإجراء الأساسي.
- أخضر للنجاح، برتقالي للتدخل، وأحمر للفشل.
- بطاقات دائرية وشريط تنقل سفلي.
- صورة المتصفح هي العنصر المركزي أثناء التنفيذ.

## الربط الحالي

- إنشاء المهمة.
- قراءة حالة المهمة.
- لقطة المتصفح الحية.
- إدخال بشري عند الانتظار.
- استئناف المهمة.
- إلغاء المهمة.
- تحديد الميزانية ومراقبة الاستهلاك.

## المصدر

يوجد ملف مصدر بصيغة رموز التصميم داخل المستودع، ونسخة SVG كاملة يمكن استيرادها إلى فيجما من ملفات التسليم الخارجية.
