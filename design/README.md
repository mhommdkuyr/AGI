# تصميم واجهة وكيل الويب

هذه الوحدة تحفظ مواصفات الواجهة الهاتفية الأولية وربطها بمحرك التنفيذ.

## الشاشات
- الرئيسية: إدخال الهدف والميزانية.
- التنفيذ المباشر: صورة المتصفح، الحالة، الجولات، والإلغاء.
- تدخل المستخدم: إشعار المصادقة أو التحقق مع استكمال المهمة.
- المهام: السجل والاستهلاك.
- الإعدادات: الحساب، الخصوصية، الإشعارات، الفوترة، والأمان.

## المظهر
- الاتجاه: من اليمين إلى اليسار.
- مقاس الإطار المرجعي: 390 × 844.
- واجهة داكنة مع أزرق كإجراء أساسي.
- أخضر للنجاح، برتقالي للتدخل، أحمر للفشل.
- بطاقات دائرية وشريط تنقل سفلي.
- شاشة المتصفح عنصر مركزي أثناء التنفيذ.

## الربط
- إنشاء المهمة.
- قراءة حالة المهمة.
- لقطة المتصفح الحية.
- تحكم بشري محدود أثناء حالة الانتظار.
- استئناف المهمة.
- إلغاء المهمة.

ملف التصميم المرئي النهائي القابل للاستيراد إلى فيجما مُسلّم خارج المستودع بصيغة SVG.
