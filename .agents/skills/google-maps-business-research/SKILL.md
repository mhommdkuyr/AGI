# حصر المنشآت التجارية والبحث الجغرافي

## الهدف
إنشاء قائمة موثقة بالمنشآت ضمن مدينة أو نطاق جغرافي، مع تقليل التكرار وتوثيق التغطية بدل الادعاء بأن القائمة شاملة دون دليل.

## الحقول المقترحة
- الاسم التجاري
- الفئة/النشاط
- العنوان المعروض
- خط العرض وخط الطول
- رقم الهاتف العام المنشور
- الموقع الإلكتروني أو الحساب الرسمي إن توفر
- رابط صفحة المكان أو المصدر
- معرّف المكان الثابت إن كان متاحًا
- مصدر البيانات وتاريخ آخر تحقق
- حالة التحقق ومستوى الثقة وملاحظات التعارض

## سير العمل
1. ثبّت حدود المدينة أو المنطقة والفئات المطلوبة، أو اقترح تقسيمًا واضحًا للنطاق إلى أحياء/مربعات جغرافية وفئات بحث.
2. استخدم مصادر الأماكن والأعمال المتاحة فعليًا، مثل Google Maps Platform/Places عند إعدادها، أو أدوات بحث الأعمال والويب المتصلة. افحص الوثائق والشروط الحالية قبل اختيار طريقة الجمع.
3. أنشئ مصفوفة استعلامات تغطي أنواع النشاط المختلفة، وأسماء الفئات المحلية والمرادفات الشائعة. قسّم البحث جغرافيًا وسجّل المناطق والفئات التي جرى فحصها.
4. اجمع الحقول التي يعرضها المصدر فقط. إذا لم يعرض المصدر رقمًا أو موقعًا إلكترونيًا فلا تخمّنه ولا تولّده.
5. أزل التكرارات بهذا الترتيب: معرّف المكان الثابت، ثم رقم الهاتف مع تطابق مناسب، ثم الاسم الموحّد والعنوان/الإحداثيات. أبقِ سجلات التعارض للمراجعة بدل حذفها تلقائيًا.
6. افصل المنشآت المؤكدة عن المرشحة والمتعارضة والمغلقة أو التي لم يمكن التحقق منها. لا تعتبر تكرار الأسماء وحده دليلًا كافيًا على التكرار.
7. اختبر عيّنة من السجلات مقابل صفحة المصدر الفعلية، واحتفظ بالرابط وتاريخ التحقق. أخرج CSV/JSON بترميز UTF-8، مع تقرير بعدد السجلات الخام والفريدة والمستبعدة وأسباب الاستبعاد.
8. اذكر حدود النتائج: الصفحات غير المتاحة، قيود النتائج، الفئات غير المغطاة، أو غياب الوصول إلى مصدر مباشر.

## حدود المنصة والخصوصية
لا تنفّذ كشطًا جماعيًا يتجاوز شروط المنصة أو تتجاوز الحماية التقنية. استخدم API أو مصادر عامة مسموحًا بها عند ملاءمتها، واحترم حدود المعدّل وشروط عرض بيانات الأماكن. لا تجمع بيانات شخصية غير منشورة للعامة ولا تستنتجها.
