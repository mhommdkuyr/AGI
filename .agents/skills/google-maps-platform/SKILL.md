# تطوير تطبيقات خرائط Google

## مسار التنفيذ
1. حدّد المطلوب: خريطة عرض، بحث أماكن، جلب تفاصيل مكان، ترميز جغرافي، مسارات، تجميع علامات، أو تطبيق ثلاثي الأبعاد.
2. قبل كتابة الشيفرة، راجع أحدث وثائق Google Maps Platform للواجهة وAPI المحددة؛ لا تعتمد على ذاكرة النموذج وحدها عند تغيّر أسماء الخدمات أو متطلبات المصادقة.
3. افصل بين بيانات الخريطة الأساسية وبين بيانات المنشآت التجارية التي تحتاج مصدرًا مستقلًا. هذه المهارة تساعد على بناء التطبيق، ولا تعني أنها ستجمع كل منشآت المدينة تلقائيًا.
4. استخدم معرّفات وحقول API الفعلية، وتعامل مع الفشل وحدود المعدّل والصفحات التالية. أضف حالات تحميل وفشل وعدم وجود نتائج.
5. لا تضع مفاتيح API أو الأسرار في الشيفرة أو المستودع. استخدم متغيرات بيئة/إعدادات أسرار، وقيّد المفاتيح حسب النطاق والـAPI، ووضّح أي رسوم أو حدود استخدام حالية قبل الإنتاج.
6. في الخريطة التفاعلية، نفّذ البحث والفلاتر والقائمة الجانبية والتجميع الجغرافي ونافذة تفاصيل المكان مع دعم RTL عند طلب واجهة عربية.
7. اختبر النقر على العلامات، التكبير/التصغير، الفلاتر، الروابط، حالات الخطأ والتصميم المتجاوب. لا تستخدم بيانات وهمية على أنها نتائج حقيقية.
