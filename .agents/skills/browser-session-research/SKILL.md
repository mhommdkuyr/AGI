# البحث عبر المتصفح الحقيقي

## الهدف
تنفيذ تدفقات تصفح عملية، بما فيها الصفحات التي تُحمّل بياناتها عبر JavaScript، مع التمييز بين التصفح العام والجلسات التي تحتاج تسجيل الدخول.

## طريقة التنفيذ
1. تحقّق أولًا من وجود متصفح أو اتصال Browser Agent متاح في البيئة الحالية. في هذا المشروع، Playwright هو طبقة تنفيذ المتصفح الموضحة في README؛ افحص التنفيذ الحالي قبل افتراض تفاصيل API.
2. إذا كان TinyFish أو BrowserSkill أو أداة متصفح أخرى متصلة بالفعل، استخدمها فقط ضمن الصلاحيات والصفحات المصرح بها. لا تدّعِ أن الاتصال موجود إذا لم تؤكده الأداة.
3. افتح الصفحة، وانتظر اكتمال المحتوى الديناميكي، ثم افحص النص المرئي وروابط التنقل وحالة الصفحة. استخدم DOM ولقطات الشاشة عند الحاجة.
4. في الجداول والنتائج متعددة الصفحات، استخرج كل صفحة متاحة وسجّل ما إذا كانت هناك صفحات متبقية. لا تعتبر أول صفحة مجموعة كاملة.
5. لا ترسل نماذج أو تغيّر إعدادات أو تحذف بيانات أو تنفّذ عمليات شراء/نشر دون طلب صريح من المستخدم.
6. عندما يطلب الموقع تسجيل الدخول أو MFA أو CAPTCHA، استخدم المسار الرسمي واطلب من المستخدم إكمال التحقق؛ لا تتجاوز الحاجز ولا تستخرج ملفات تعريف الارتباط أو كلمات المرور.
7. سجّل الرابط النهائي وتاريخ الوصول، ونبّه إلى المحتوى الذي قد يكون ناقصًا أو محجوبًا.

## تركيب عميل متصفح اختياري
يمكن تثبيت BrowserSkill من Tencent في بيئة محلية متوافقة، لكنه برنامج CLI/إضافة متصفح منفصل وليس مجرد ملف تعليمات:
https://github.com/Tencent/BrowserSkill

اتبع تعليمات التثبيت الرسمية بالمستودع، ثم تحقّق من ظهور CLI والإضافة والجلسة قبل الاستخدام. وجود هذا الملف في GitHub لا يثبت أن BrowserSkill ثُبّت على جهاز المستخدم أو أن جلسة Chrome الشخصية متاحة للوكيل.
